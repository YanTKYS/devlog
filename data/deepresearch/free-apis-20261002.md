## DeepLの確認結果

DeepLについては、**「DeepL API Developer＝累計100万文字、月次リセットなし」という認識を、この調査だけで公式に確定することはできなかった**。取得できた公式開発者向けUsage limitsは、依然として「DeepL API Free＝月50万文字」と記載し、Free用エンドポイントとして `api-free.deepl.com` を案内している 。 [developers.deepl](https://developers.deepl.com/docs/resources/usage-limits.md)

一方、2026年の現行料金画面を参照した第三者資料では、API Developerを「1回限り100万文字」と説明しており、プラン移行が進んでいる可能性が高い 。ただし、これは無料条件を確定する一次資料としては不十分である。 [translatebot](https://translatebot.dev/docs/integrations/deepl/)

したがって、ノートでは次のように記載するのが安全である。

> DeepLでは新料金体系の「API Developer」が案内される場合があり、累計100万文字の初回クレジットと表示される。旧「DeepL API Free」は月50万文字として公式開発者文書に残っている。地域・既存契約・移行状況によって表示が異なる可能性があるため、新規登録時の公式プラン選択画面で確認すること。

旧Freeユーザーと新規Developerユーザーを同一条件として扱わず、「旧プラン」「新規向けプラン」を分けるべきである。

## 日本の公共API・オープンデータ

### 優先追加

**統計ダッシュボード WebAPI**は、今回の追加候補で特に有力である。利用登録不要で、系列・地域・用語・社会事象等のメタデータと統計値をREST形式のJSON・XML・CSVで取得でき、e-Stat APIより短時間で可視化PoCを作りやすい 。 [dashboard.e-stat.go](https://dashboard.e-stat.go.jp/static/api)

**Gビズインフォ REST API v2**は、法人番号だけでなく、政府保有の法人活動情報を扱う用途に向く。利用申請は必要だが、Swaggerが公開され、APIの明示的な固定上限はなく、集中アクセス時に制限される方式である 。 [help.info.gbiz.go](https://help.info.gbiz.go.jp/hc/ja/sections/4795198109726-REST-API%E5%88%A9%E7%94%A8%E3%83%9E%E3%83%8B%E3%83%A5%E3%82%A2%E3%83%AB)

**EDINET API Version 2**は、有価証券報告書等を取得して、XBRL・PDF・LLMを組み合わせる技術検証に適している。APIキー登録が必要であるため、完全なキー不要APIとは分ける 。 [disclosure2.edinet-fsa.go](https://disclosure2.edinet-fsa.go.jp/)

### NDL系

国立国会図書館のAPI群は、単に「NDL Search API」一項目にまとめるより、次のように分けると用途が明確になる。

- NDL Search SRU / OpenSearch：書籍・資料の検索
- OAI-PMH：書誌メタデータの一括収集
- SPARQL：全国書誌・典拠データの関係検索
- 国会会議録API：発言・会議検索
- 次世代デジタルライブラリー：全文検索・IIIFの実験
- RSS：新着書誌・件名等の更新監視

国立国会図書館が作成した書誌・典拠・雑誌記事索引データは、営利・非営利を問わず無償利用可能な範囲が明示されている一方、API利用自体は用途によって申請が必要となる 。 [ndl.go](https://www.ndl.go.jp/use/api)

### 防災・気象

気象庁防災情報XMLは、APIキー不要だが、確実なリアルタイム配信を保証するサービスではない。高頻度Atomフィードは毎分更新、長期フィードは毎時更新で、1日10GB以上のダウンロードを伴うアクセスは遮断対象となる 。 [xml.kishou.go](https://xml.kishou.go.jp/xmlpull.html)

自治体でのPoCでは、全XMLを毎回再取得せず、Atomフィードの更新ID・リンクを保存して未取得電文のみ取得する必要がある。キャッシュ、重複排除、再試行制御を実装することが重要である。

## 生成AI・検索関連

個人開発で継続利用しやすいLLM APIは、2026年10月時点ではGroq、Mistral Free mode、Geminiの対象モデル、Cloudflare Workers AIが中心となる。CohereとCerebrasはTrialまたは評価用、JinaとVoyageは初回トークン付与型、Hugging Faceは月$0.10相当の小規模枠として扱うべきである 。 [console.groq](https://console.groq.com/docs/overview)

検索系では、Brave Searchが月$5クレジット、Tavilyが月1,000クレジットである。Tavilyはカード不要かつキーなし低レート利用もあるため、最初のエージェントPoCでは導入しやすい 。 [brave](https://brave.com/search/api/)

Jina Readerは検索APIではないが、検索結果URLから本文をMarkdown化する中間層として有用である。BraveやTavilyの結果をそのままLLMに渡すより、Readerで本文抽出してからRerank・要約する構成に向く 。 [jina](https://jina.ai/ja/reader/)

## OCR・音声・翻訳

OCRではGoogle Cloud Visionの月次無料枠に加え、OCR.spaceを軽量比較候補として追加できる。ただしOCR.spaceの無料枠はファイルサイズ1MBで、機密文書や個人情報を含む文書を外部送信する用途には適さない 。 [ocr](https://ocr.space/ocrapi)

音声認識ではGroqのWhisper Large v3系がFree Plan内で利用できる。ブラウザ内完結が許容される場合は、Chrome系のWeb Speech APIにもオンデバイス音声認識が導入されているが、ブラウザ・OS依存であるため、汎用サーバーAPIとは別枠にする 。 [developer.chrome](https://developer.chrome.com/release-notes/139)

音声合成は、閉域・ローカル要件を重視する場合、VOICEVOX ENGINEを維持するのが妥当である。クラウドAPIの無料枠と比較せず、「ローカル実行・キャラクター規約あり」と分類する。

翻訳ではDeepLの新旧プラン記述が不整合であるため、無料文字数を最も慎重に扱う必要がある。登録画面で「API Developer・累計100万文字」が確認できた場合のみ、その画面確認日を併記して採用することを推奨する。

## 地図・GIS・交通

地図・GIS分野は、国土地理院、国土数値情報、PLATEAU、ABR、国土交通データプラットフォーム、ODPTの組み合わせが強い。APIかファイル配布か、データ本体かカタログAPIかを明確に分けると誤認を減らせる。

| サービス | 実体 | 主な形式 | 向く用途 |
| --- | --- | --- | --- |
| 地理院タイル | 配信API相当 | PNG、標高CSV、ベクトルタイル | 背景地図、標高、防災 |
| 国土数値情報 | ファイル配布 | Shapefile、GeoJSON、GML | 行政界・施設・災害リスク |
| PLATEAU | カタログ＋都市モデル配信 | 3D Tiles、MVT、CityGML | 3D都市、防災、景観 |
| ABR | データセット＋OSS | CSV、ローカルHTTP処理 | 住所正規化、名寄せ |
| 国交省DPF | 横断API | GraphQL | インフラデータ探索 |
| ODPT | 交通API | JSON / JSON-LD | 鉄道、バス、時刻表 |
| Open-Meteo Elevation | REST API | JSON | 簡易標高取得 |

Open-Meteoの標高APIは非商用無料枠に含まれるため、地理院標高タイルのパースより簡単に試せる。ただし公開・商用化する場合は有料プランへの移行が必要である 。 [open-meteo](https://open-meteo.com/en/terms)

## 学術・書籍・情報検索

既存のarXiv、Crossref、OpenAlex、Wikimediaに、Open LibraryとGoogle Booksを追加すると、学術論文だけでなく一般書籍・ISBN・表紙画像まで扱える。日本語資料の正確性を重視する場合はNDLを主とし、Open Library・Google Booksを補完にする。

NDL書誌APIとGoogle Books・Open Libraryの検索結果をISBNで突合すれば、タイトル表記、著者、出版年、表紙画像、所蔵情報を補完できる。Open Libraryは公共的な書籍発見用途を前提とし、JSON・YAML・RDF/XMLと表紙APIを提供する 。 [openlibrary](https://openlibrary.org/developers/api)

OpenAlexの無料枠は「無制限無料」ではなく日次利用額枠である。大量分析ではスナップショット利用やキャッシュを検討し、APIを逐次全件取得する設計を避ける。

## 開発支援・実用系

CloudflareはWorkers AIだけでなく、R2、Vectorize、Browser Rendering、Workflowsまで無料枠がつながっている。これらを同一アカウント上で組み合わせれば、検索・抽出・埋め込み・保存・LLM要約を小規模に完結できる 。 [cloudflare](https://www.cloudflare.com/pricing.md)

ただしPaidプランへ変更すると、無料割当を超えた分が従量課金になるサービスがある。無料枠として紹介する場合は、「Free Planは停止」「Paid Planは超過課金」という違いをサービスごとに明記すべきである。

GitHub REST APIはコード分析・Issue整理・リリースノート生成に引き続き有力である。GitHub Models終了後は、GitHub APIで取得した情報をGroq、Gemini、Mistral等へ送る構成に置き換える。

RESAS-APIは2025年3月24日に提供終了しており、新規アカウント作成も2024年10月31日に停止された。RESASのWeb画面やポータルは残っているが、API候補には戻さない 。 [opendata.resas-portal.go](https://opendata.resas-portal.go.jp/docs/api/v1/index.html)

- RESAS画面での分析：Webサービスとして継続利用

GitHub Modelsは2026年7月30日に完全終了した。Playground、モデルカタログ、Inference API、BYOKの全機能が、既存利用者を含め利用できない 。 [github](https://github.blog/changelog/2026-07-30-github-models-is-now-retired/)

「無料枠終了」ではなく「サービス終了」であるため、利用可能API一覧から削除し、終了済み欄だけに残す。GitHub Copilotとは別サービスである。

- **OpenWeatherMap:** 1日1,000回無料だけでなく、超過従量課金・支払い情報・上限設定を強調 。 [old.openweathermap](https://old.openweathermap.org/price)

## 今回の重要な発見

1. **GitHub Modelsは2026年7月30日に完全終了**しており、既存利用者・Inference API・BYOKを含め利用不可である 。 [github](https://github.blog/changelog/2026-07-30-github-models-is-now-retired/)
2. **RESAS-APIは2025年3月24日に終了済み**で、RESASのWeb画面が残っていてもAPI候補には戻せない 。 [opendata.resas-portal.go](https://opendata.resas-portal.go.jp/docs/api/v1/index.html)
3. **DeepL API Developerの累計100万文字は、取得できた公式開発者文書と整合しない**。旧API Freeの月50万文字記載が残っているため、新規登録画面での確認が必要 。 [developers.deepl](https://developers.deepl.com/docs/admin/api-key-permissions)
4. **Hugging Face無料ユーザーのInference Providers枠は月$0.10分**であり、本格的な継続無料枠ではなく動作確認用に近い 。 [huggingface](https://huggingface.co/docs/inference-providers/pricing.md)
5. **Jina AIは全体をTrial扱いすべきではない**。新規キーの1,000万トークンは初回付与だが、Reader基本利用はキーなし無料 。 [jina](https://jina.ai/ja/reader/)
6. **統計ダッシュボード WebAPIは有力な追加候補**で、登録不要、JSON・XML・CSV対応、主要統計の地域・時系列取得に適する 。 [dashboard.e-stat.go](https://dashboard.e-stat.go.jp/static/api)
7. **Gビズインフォ REST API v2とEDINET API Version 2**は、法人・企業・開示情報のPoCに有用な公共APIとして追加価値が高い 。 [content.info.gbiz.go](https://content.info.gbiz.go.jp/api/index.html)
8. **気象庁防災情報XMLには1日10GBの遮断基準**があり、差分取得・キャッシュを前提とした設計が必要 。 [xml.kishou.go](https://xml.kishou.go.jp/xmlpull.html)
9. **MistralはMistral Studioへ名称を統一**し、最新QuickstartではFree modeが既定・カード不要と案内されている 。 [docs.mistral](https://docs.mistral.ai/getting-started/quickstarts/developer/first-api-request)
10. **e-Gov法令API Version 2の正式リリース日は2025年3月19日**で、現行ノートの日付は修正対象となる 。 [laws.e-gov.go](https://laws.e-gov.go.jp/news/)
